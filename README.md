# Bank Management System Using MySQL

## Project Objective
This project is a MySQL-only Bank Management System designed to demonstrate DBMS concepts such as table design, relationships, CRUD operations, stored procedures, triggers, transactions, views, and reporting.

## Features
- Customer management
- Account management
- Deposit, withdrawal, and transfer operations
- Balance tracking and transaction history
- Loan management
- Employee/admin management
- SQL reports and summaries
- Automated balance updates using triggers

## Database Schema
Tables used:
- customers
- accounts
- transactions
- loans
- employees

## Tools Used
- MySQL
- MySQL Workbench

## Setup Instructions
1. Open MySQL Workbench.
2. Create a new SQL script file.
3. Paste the complete SQL script.
4. Execute the script step by step or as a whole.
5. Run procedure calls and report queries to test functionality.

## How to Execute
- First run the CREATE DATABASE and CREATE TABLE statements.
- Then run sample INSERT statements.
- After that, run triggers, stored procedures, views, and indexes.
- Finally, execute report queries and test procedure calls.

## Notes
- This project is fully implemented using SQL and MySQL features only.
- It is suitable for DBMS mini-project submissions and interview demonstrations.
